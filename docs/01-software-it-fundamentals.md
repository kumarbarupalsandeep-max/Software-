# 01 — Software & IT Fundamentals

[← Learning index](../README.md)

## Software kya hai?
Software instructions aur programs ka set hai jo computer ko batata hai kya karna hai. Example: calculator app numbers calculate karti hai, browser websites kholta hai.

## IT kya hai?
Information Technology ka use information ko create, store, process, secure aur share karne ke liye hota hai. Office laptops, Wi-Fi, email, databases aur backups IT environment ka hissa hain.

## IT Services kya hain?
Kisi organization ke technology systems ko build, configure, manage, secure ya support karna IT services mein aata hai. Example: cloud server manage karna, website banana ya employee laptop troubleshoot karna.

## Software Development vs IT Services
- Software development: requirements, design, code, test aur software maintain karna.
- IT services: setup, integration, migration, support aur operations. Ismein development bhi shamil ho sakta hai.
- Dono overlap karte hain.

## IT industry ka workflow
Business problem → requirements → design → build/configure → test → release → monitor/support → improve.

Example: retailer online store chahta hai. Team products, cart, payments aur delivery requirements samajhti hai, store build/test karti hai aur release ke baad maintain karti hai.

## Products vs Services
Product reusable solution hai jo kai customers use karte hain. Service customer ke liye expertise, implementation ya ongoing work hai. Generic accounting app product hai; business ke liye usko configure karna service hai.

## Hardware, Software, Firmware
- Hardware: physical parts, jaise CPU, keyboard, router.
- Software: applications aur operating systems.
- Firmware: device ke andar low-level program jo hardware control karta hai.
Example: router hardware hai, admin app software hai, internal control program firmware hai.

## System software vs Application software
System software hardware/resources manage karta hai, jaise operating system. Application software user ka task complete karta hai, jaise browser, spreadsheet ya photo editor.

## Revision
1. Software instructions hain; hardware physical hai.
2. IT broad field hai; IT services technology work deliver karti hain.
3. Development, deployment aur support ek lifecycle ke connected parts hain.

2. Ek product aur ek IT service ka example do.
3. Kisi local business ki technology problem identify karo.
