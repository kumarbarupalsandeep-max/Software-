# Software & IT Services Academy

A beginner-friendly, example-based study website for learning Software & IT Services from fundamentals to advanced industry topics.

## Run locally

Open `index.html` in a modern browser. No build tools or backend are required.

## Learning roadmap
1. Software and IT fundamentals
2. Software products vs services
3. SDLC and development methodologies
4. Programming languages and web development
5. Databases, APIs and integrations
6. Cloud computing, DevOps and CI/CD
7. System design, scalability and architecture
8. Cybersecurity and privacy
9. QA, testing and reliability
10. IT operations, support and service management
11. Enterprise systems and business domains
12. Project management, careers and business models

## Features
- Searchable topic cards
- Simple explanations and practical examples
- Learning progress saved in browser local storage
- Responsive layout for desktop and mobile
- Self-check quiz

## Scope note
This is a learning resource, not a certification course. Use the examples as starting points and verify production decisions against current documentation and security requirements.
